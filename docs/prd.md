# PRD — 모임장

동아리/학회 운영진(모임장)이 일정·부원 명단·출석·정산·회의·자료를 한 앱에서 관리하는 서비스.
이 문서는 기능 요구사항과 전역 정책을 정리한다. 화면 단위 상세는 Figma, 엔드포인트 단위 상세는
`docs/api-spec.md`, 데이터 모델은 `docs/erd.md`를 본다.

## 범위

- **포함**: 그룹/기수 관리, 일정·운영 공간, 부원 명단·등록 링크, 참석·출석, 영수증·정산·입금,
  운영 메모, 회의·회의록·AI 요약, 문서함(자료실)·예산(장부), AI 운영 비서
- **제외(데모 범위)**: 로그인/회원가입/인증, 운영진 초대·권한 관리, 모임장 권한 이전

## 도메인별 핵심 기능

| 도메인 | 핵심 기능 |
|---|---|
| 그룹 | 그룹 생성/조회/수정(그룹명·기수) |
| 일정 | 일정 등록·수정·삭제, 카테고리 관리, 캘린더/다가오는 일정 조회, 운영 공간 함께 생성 |
| 운영 공간 | 일정·회의록 통합 목록, 일정 상세에서 회의록 생성, 안건 연결·해제 |
| 부원 명단 | 명단방 생성(수집 항목 토글), 등록 링크로 공개 등록, 운영진 직접 추가/수정/삭제 |
| 출석 | 차수 관리, 부원링크/현장 추가 참가자, 출석 처리, 동명이인 매칭 |
| 정산 | 영수증 등록(AI 인식 지원)·조회·삭제, 정산 명단·청구액 계산, 입금 확인, 정산 공지 생성 |
| 운영 메모 | 일반메모/할일/결정사항/아이디어 작성·수정·삭제, 할 일 완료 처리 |
| 회의 | 회의 생성·진행·종료, 안건 관리, AI 요약, 회의록 저장(일정에 속한 회의록 포함) |
| 문서함 | 기수별 자료 업로드/조회/삭제(되돌리기 가능), 분류(활동문서/예산안/활동사진/장부), ZIP 다운로드 |
| 예산 | 장부 조회(엑셀 원본 + 서비스 입출금 내역), 직접 입력, 정산 연동 자동 반영 |
| AI 비서 | 대화방 기반 질의응답(예: "미입금자 알려줘"), 결과 카드에서 바로 입금 확인 등 액션 |

## 전역 정책

### 정산
- 차수당 영수증 1개. 해당 차수 출석 완료 인원을 불러와 영수증 금액에서 지원금을 뺀 금액을
  인원수로 균등 분할하고 100원 단위로 버림. 개인 청구액은 참여한 모든 차수 금액의 합.
- 영수증 삭제 시 연결된 차수·정산 명단·청구 내역도 함께 삭제. 단, 장부에 이미 반영된 내역·잔액은
  유지(상세: `docs/decisions.md` #4). 입금 후에는 영수증 수정·삭제 제한.
- 카드 스와이프: 미입금/미출석 → 삭제, 입금완료/출석완료 → 되돌리기.
- 차수 전원 납부 완료 시 실제 총 납부액은 수입 1건, 버림 차액 합계는 "추가 동아리 지원금" 지출 1건으로
  자동 반영(상세: `docs/decisions.md` #2).

### 식별정보
- 현장 참가자: 이름·학과/소속·전화번호 뒤 4자리 필수.
- 부원 등록: 이름·학과 필수, 나머지 수집 항목은 명단방에서 토글로 설정(`docs/decisions.md` #7).

### 권한
- 일반 운영진도 일정·명단·출석·정산·메모·회의록·자료 등록/수정/삭제 가능.
- 모임장 권한 이전, 운영진 내보내기는 이번 범위 제외(`docs/decisions.md` #1).

### 삭제
- 명단 삭제: 명단방·등록 부원·연결된 출석·정산 기록 전체 삭제, 등록 링크 닫음.
- 일정 삭제: 일정·운영 공간·메모·출석·정산·첨부 자료와 **그 일정에서 만든 회의록**(안건·요약 포함)을
  함께 삭제한다. 안건만 연결해 둔 경우는 연결만 끊고 그 안건과 회의록은 남긴다. 일정과 무관한
  회의록·부원 원본 명단도 유지(`docs/decisions.md` #44).
  두 삭제 모두 영향 범위 안내 후 확인.

### 회의
- 중단 시 저장 후 이어하기. 일정은 종료 시간 경과 시, 회의는 종료 버튼 실행 시 지난 기록으로 이동.
- 회의록이 일정과 엮이는 경로는 둘이다(`docs/decisions.md` #44). 일정 상세에서 "회의록 작성하기"로
  만든 회의록은 그 일정에 통째로 속하고, 그 외 회의록은 **안건 하나하나만** 일정에 연결한다.
- 안건 연결은 사용자가 직접 고른다 — 어느 일정에도 속하지 않은 안건 전체를 모달에 띄우고,
  선택해서 추가한다. 내용을 분석해 자동으로 붙여 주는 기능은 없다(`docs/decisions.md` #45).
- 연결 해제는 그 연결만 끊고 원본 회의록·안건은 유지.
- 종료된 회의의 안건도 일정에 연결할 수 있다. 다만 그 안건의 논의 내용·결정 사항은 일정 상세에서
  읽기 전용이다 — 회의가 끝나면 회의록이 확정되기 때문(`docs/decisions.md` #46).

### 파일
- 문서함은 일정과 무관한 일반 자료도 올리는 기수별 보관 공간. 일정 상세에서 올린 자료는 문서함에도
  자동 노출되고, 일정 삭제 시 함께 삭제. 한 번에 1개 업로드.

### 탈퇴
- 남은 운영진이 있으면 먼저 합류한 운영진에게 모임장 자동 이전. 혼자 남은 모임장도 최종 확인 후
  탈퇴·그룹 삭제 가능. (이번 범위에서는 구현 보류, `docs/decisions.md` #1)

### 장부(예산)
- 장부 원본(엑셀)은 보관하고, 서비스 입출금 내역으로 화면 잔액을 갱신하되 원본 파일은 수정하지 않는다.
- 영수증 원금과 기존 동아리 지원금은 각각 별도 지출로 기록. 참가자별 청구액은 (영수증 금액 − 지원금)
  ÷ 대상 인원을 100원 단위로 버려 계산하며, 청구 예정액 자체는 장부에 표시하지 않는다.
- 각 차수 전원 납부 완료 시에만 실제 납부 총액(수입 1건)과 버림 차액 합계("추가 동아리 지원금" 지출
  1건)를 자동 기록. 부분 납부 중에는 두 행을 만들지 않고, 차액이 0원이면 지원금 행도 만들지 않는다.
  납부를 되돌리면 두 행도 취소하고, 재완료 시 중복 없이 재반영.
- 기초 잔액(장부 파일 기준 총액) 자동 인식은 보류 상태(`docs/decisions.md` #10).

### 그룹 인수인계
- 기존 그룹에 운영진을 추가하면 그룹명·이전 기수 장부·입출금 기록을 유지한 채 이어서 쓴다.
  신규 그룹을 만들면 이전 데이터는 자동 승계되지 않으므로, 이전 그룹의 장부 원본과 서비스 장부를
  각각 다운로드해 인계해야 한다.
